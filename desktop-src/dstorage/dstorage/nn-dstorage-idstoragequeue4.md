# IDStorageQueue4 interface (dstorage.h)

Represents a DirectStorage queue to perform read operations, allowing enqueuing an operation to set a specific event object to a signaled state. Also allows you to obtain information about the queue, including the compression format it declared at creation.

## Inheritance

The **IDStorageQueue4** interface inherits from the [**IDStorageQueue3**](nn-dstorage-idstoragequeue3.md) interface.

## Methods

The **IDStorageQueue4** interface has these methods.

| &nbsp; |
| ---- |
| [IDStorageQueue4::Query1](../dstorage/nf-dstorage-idstoragequeue4-query1.md) <br><br> Obtains information about the queue, including the compression format it declared at creation.|
